# USB Serial протокол (Romeo ↔ хост, например Raspberry Pi)

Интерфейс: **USB CDC**, в коде `Serial`, скорость **115200** 8N1 (для CDC число формально не критично, но задаётся в `config.h`).

Строки заканчиваются **`\n`** (префикс `\r` игнорируется).

## Команды хост → плата

| Команда | Пример | Описание |
|---------|--------|----------|
| `PING` | `PING` | Проверка связи |
| `M1` | `M1 200` | Мотор 1, скорость −255…255 |
| `M2` | `M2 -180` | Мотор 2 |
| `S1` | `S1 90` | Серво 1, угол 0…180 |
| `S2` | `S2 45` | Серво 2 |
| `FIRE` / `IR` | `FIRE` | Импульс ИК-передатчика (~38 кГц, короткий) |
| `STOP` | `STOP` | Оба мотора в 0 |

Успех: строка `OK`. Ошибка: `ERR <код>`.

## Сообщения плата → хост

| Сообщение | Пример | Описание |
|-----------|--------|----------|
| Загрузка | `BOOT ROMEO_USB_PROTO 1` | После reset |
| Ответ на PING | `PONG 1` | |
| Попадание (ИК-приёмник) | `EVT HIT <seq> <t_ms>` | `t_ms` = `millis()` на момент события (после антидребезга) |

Очередь попаданий ограничена (`config.h`); при переполнении часть событий теряется.

## Пины (Romeo V2.2 DFR0225)

См. `src/config.h`: моторы 4–7, сервы 9–10, ИК LED 11, ИК приёмник 3.

При смене проводки правьте только `config.h`.
