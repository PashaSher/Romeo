================================================================================
  USB-протокол управления Romeo (прошивка ROMEO_USB_PROTO)
  Интерфейс: виртуальный COM-порт (USB CDC), как в Arduino Leonardo
================================================================================

ПАРАМЕТРЫ ПОРТА
  Скорость (для настройки терминала): 115200
  Формат: 8 бит данных, без чётности, 1 стоп-бит (8N1)
  Окончание строки: символ LF (0x0A), в коде '\n'
  Символ CR (0x0D), '\r', игнорируется

ФОРМАТ КОМАНД (хост → плата)
  Одна команда = одна текстовая строка в кодировке ASCII.
  Первая лексема — имя команды, далее через один пробел — аргумент (если нужен).
  Регистр букв в имени команды не важен (ping = PING).

--------------------------------------------------------------------------------
КОМАНДЫ (отправлять с переводом строки \n в конце)
--------------------------------------------------------------------------------

PING
  Проверка связи.
  Пример байтов (ASCII):  P I N G \n
  Ответ: одна строка  PONG 1

?  (или HELP, H)
  Справка: несколько строк с перечнем команд, в конце строка OK.

MF
  Оба мотора вперёд с фиксированной «крейсерской» скоростью (cfg::kMotorCruiseSpeed в config.h, по умолчанию 220).
  Ответ: OK

MB
  Оба мотора назад с той же скоростью по модулю.
  Ответ: OK

MS
  Оба мотора в 0 (то же действие, что у STOP).
  Ответ: OK

M1 <скорость>
  Двигатель 1 (встроенный драйвер). Скорость: целое от -255 до 255.
  Знак: направление, модуль: ШИМ (чем больше по модулю, тем быстрее).
  Примеры:
    M1 0\n      — останов
    M1 200\n    — вперёд (условно)
    M1 -200\n   — назад
  Ответ при успехе: OK
  Ошибки: ERR ARG (нет числа), ERR M1_VAL (не распознано число)

M2 <скорость>
  То же для двигателя 2.
  Ошибки: ERR ARG, ERR M2_VAL

S1 <угол>
  Сервопривод 1. Угол в градусах 0…180 (целое).
  Пример: S1 90\n
  Ответ: OK
  Ошибки: ERR ARG, ERR S1_VAL

S2 <угол>
  Сервопривод 2.
  Ошибки: ERR ARG, ERR S2_VAL

FIRE
  Короткий импульс ИК-передатчика (несущая ~38 кГц, длительность задаётся в прошивке).
  Пример: FIRE\n
  Ответ: OK

IR
  Синоним FIRE (та же функция).
  Пример: IR\n

STOP
  Оба мотора в 0 (M1 и M2). Эквивалентно команде MS.
  Пример: STOP\n
  Ответ: OK

--------------------------------------------------------------------------------
ОТВЕТЫ И СОБЫТИЯ (плата → хост)
--------------------------------------------------------------------------------

OK
  Команда принята и выполнена без ошибки (где применимо).

ERR <код>
  Ошибка разбора или выполнения. Коды:
    ARG       — не хватает аргумента (например, послали M1 без числа)
    M1_VAL    — неверное значение для M1
    M2_VAL    — неверное значение для M2
    S1_VAL    — неверное значение для S1
    S2_VAL    — неверное значение для S2
    LINE_OVF  — строка команды длиннее буфера (обрезание/сброс)
    UNKNOWN   — неизвестная команда

PONG 1
  Ответ на PING.

BOOT ROMEO_USB_PROTO 1
  Однократно при старте/сбросе микроконтроллера (после подключения USB может
  появиться не сразу — дождитесь порта).

EVT HIT <seq> <t_ms>
  Зарегистрировано «попадание» по ИК-приёмнику (фронт по схеме в прошивке).
    seq   — порядковый номер события (uint16)
    t_ms  — значение millis() на момент события (после антидребезга)
  Пример: EVT HIT 3 12458
  Может прийти несколько строк подряд, если событий было несколько.

--------------------------------------------------------------------------------
ПРОВЕРКА С ПК (РЕКОМЕНДУЕТСЯ: Python + pyserial)
--------------------------------------------------------------------------------
  На части систем Windows класс System.IO.Ports.SerialPort нестабилен с USB CDC
  (Leonardo): команды уходят, ответа нет. Надёжный вариант — pyserial:

    pip install pyserial
    python tools/serial_ping_test.py COM14

  (подставьте свой COM из диспетчера устройств)

--------------------------------------------------------------------------------
ПРИМЕРЫ ДЛЯ RASPBERRY PI (Python 3, пакет pyserial)
--------------------------------------------------------------------------------

  import serial
  ser = serial.Serial("/dev/ttyACM0", 115200, timeout=0.1)
  ser.write(b"PING\n")
  print(ser.readline().decode().strip())   # ожидается PONG 1

  ser.write(b"M1 100\n")
  print(ser.readline().decode().strip())   # OK

  ser.write(b"S1 45\n")
  print(ser.readline().decode().strip())

  ser.write(b"STOP\n")
  ser.write(b"FIRE\n")

  # чтение входящих строк (BOOT, EVT HIT, ответы на команды):
  while ser.in_waiting:
      line = ser.readline().decode(errors="ignore").strip()
      if line:
          print(line)

--------------------------------------------------------------------------------
ПРИМЕР ДЛЯ WINDOWS (PowerShell, один порт COM5 — замените на свой)
--------------------------------------------------------------------------------

  $p = new-Object System.IO.Ports.SerialPort COM5,115200,None,8,one
  $p.Open()
  $p.WriteLine("PING")
  $p.ReadLine()
  $p.WriteLine("M1 80")
  $p.Close()
